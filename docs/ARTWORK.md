# Artwork provenance

The AeriVoice app icon and social preview were created specifically for this
repository in September 2026 under Daniel Ou's direction. The mark is an
original monochrome line drawing: a faceted octagonal microphone head with a
crossing web of facets, resting in a rounded yoke on a tripod foot. It is
drawn on a 40 × 40 grid with uniform 1.3-unit strokes and round caps, and is
reproduced in this repository as vector art in `aerivoiceweb/brand/`, from
which every raster asset is generated by `aerivoiceweb/brand/build-assets.sh`.

The mark replaces the earlier treatment (a near-black tile carrying the Aeri
script wordmark with a microphone as the dot above the `i`). That wordmark
remains part of the wider Aeri brand family and is unchanged elsewhere; it no
longer appears in AeriVoice's own icon.

The app icon has an opaque white background extending to every canvas edge,
with the mark in near-black ink. The native `AeriVoice/AppIcon.icon` package
keeps the white fill in its artwork for both light and dark icon appearances;
macOS supplies the outer icon shape. Xcode prefers this package over the
legacy `AppIcon.appiconset` raster fallback. The selected design is round 7, S10 (Yoke & Tripod) in
`aerivoiceweb/logo-candidates.html`. Small app icons and favicons use a solid
head without internal facets. The menu bar likewise uses this solid-head
variant as a template image so it follows the menu bar's light and
dark appearance. While dictation is active, the app renders native
`NSColor.systemOrange` into a non-template image so the status bar preserves
the orange. Idle uses a template image that follows the menu bar appearance.

The final artwork is original project artwork, is not an Apple system icon or
sound, and is distributed with this repository under the MIT License.

The project does not distribute the macOS native alert sounds used at runtime.
AeriVoice requests `Blow`, `Bottle`, and `Submarine` through `NSSound` on the
user's Mac.

## README demo

`images/aerivoice-demo.gif` is derived from Daniel Ou's supplied
`aerivoice qwen demo.mp4` recording from September 3, 2026. The full recording
retains its original timing, with no audio, at 800 × 600 and 20 frames per second.
It loops continuously. Palette quantization uses 96 colors and Bayer dithering (scale 5);
the GIF is approximately 2.7 MB. The source recording remains outside the repo.
