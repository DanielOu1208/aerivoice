# AeriVoice 0.2.4 — Spoken language and steadier dictation

AeriVoice 0.2.4 lets you choose the language you speak, keeps a dictation going when macOS is slow to hand over your API keys, and removes several waits and background chores across transcription providers.

### What's new

- **Spoken language:** choose a language under **Settings → Dictation → Transcription**, or keep **Auto-detect**, the default, which works as before. Soniox restricts recognition to the chosen language. Grok and Meta use it as a hint and can still follow another language. Cartesia detects its languages itself, Nemotron transcribes English, and Apple Speech keeps its own language setting. See [Providers and models](../PROVIDERS.md#spoken-language).

### What's fixed

- **A slow Keychain no longer loses the dictation:** if macOS took several seconds to return your API keys, the audio recorded meanwhile could overflow and the dictation failed. That audio is now kept and sent once the connection opens.
- **No keyboard freeze while keys load:** API keys are read off the main thread, once per dictation. Releasing the shortcut during a slow read cancels at once instead of stalling every key press until the read finished.
- **Local Nemotron ready after wake:** a model that is already loaded stays ready when you wake the Mac or change settings, instead of re-checking all of its files and refusing to dictate meanwhile. It also skips rebuilding your Dictionary hints when they haven't changed.
- **Apple Speech ready after wake:** re-checking the language you already use no longer marks it not ready.
- **Grok keeps its prepared connection** when a Dictionary edit doesn't change the terms Grok receives.

### Smaller improvements

- The clipboard check after a paste runs off the main thread.
- The last moment of audio after you release the shortcut goes out in one piece, which helps Meta and Grok finish sooner.
- Lighter background work: diagnostics housekeeping, model download progress, and API key status refreshes do less.

### Install or upgrade

Requires **Apple Silicon and macOS 26 or newer**. Use **Settings → General → Check for Updates**, or download the DMG below, open it, and drag AeriVoice into Applications. Existing settings and Keychain credentials are retained.

The DMG is Developer ID signed, notarized by Apple, and stapled. A SHA-256 checksum and debugging symbols are attached.
