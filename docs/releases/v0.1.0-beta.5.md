# AeriVoice v0.1.0-beta.5 — Paste reliability and faster Cerebras cleanup

This update improves pasting across apps and reduces connection overhead when
using Cerebras cleanup. It also adds more detailed local timing diagnostics to
help distinguish transcription delays, network setup, and provider queueing.

## What changed

- **More consistent pasting:** native, browser, Electron, and terminal text fields
  use a shared Paste operation. Editors no longer need to support direct
  Accessibility text replacement to qualify for pasting.
- **Safer focus and clipboard handling:** AeriVoice checks the app, window, and
  field captured when recording stops before sending Paste. A copy you make
  during cleanup is preserved. Detected secure, read-only, changed, or unavailable
  targets fall back to copying with an explanation when the clipboard is safe to
  update. Cancellation before dispatch prevents a late paste.
- **Green completion check mark:** the compact check mark returns after the Paste
  shortcut is sent.
- **Faster Cerebras connection startup:** AeriVoice can warm the connection while
  you dictate, reducing connection setup work when cleanup begins. Warming sends
  no transcript or audio and never prevents dictation when it fails.
- **Better latency diagnostics:** Cerebras cleanup records now separate request preparation,
  network timing, provider queueing and generation, and response decoding. Timing
  information is also retained for more failure cases, without recording your text
  or API keys.

## Performance evidence

In a small controlled Soniox → Cerebras comparison with ten samples per condition,
median cleanup time decreased from **301 ms without warming to 218 ms with
warming**. This measures the cleanup portion of the pipeline, not the time from
speaking to pasted text. Provider queueing varies, so it is not a guaranteed
speedup for every dictation or other providers.

Six additional synthetic Chinese cleanup samples preserved Simplified Chinese,
Traditional Chinese, and mixed Chinese–English text with the current English
instructions. Filler removal was incomplete in some samples; this is not a broad
multilingual quality guarantee.

## Paste behavior to know

The transcript stays on the clipboard until you replace it. The check mark means
AeriVoice sent Paste; macOS does not confirm that another app consumed it.
Some apps expose incomplete secure/read-only field information. Ghostty delivery
has not been verified in the current live checks. AeriVoice never sends Return to
submit a message, but destinations control how pasted newlines are handled.

## Updating from beta.4

The app uses the same credential namespace and preferences as beta.4. Existing
provider keys and settings are intended to carry over; macOS may request access
when needed. No automatic updater is included.

1. Quit AeriVoice.
2. Download `AeriVoice-v0.1.0-beta.5-arm64.dmg` and its `.sha256` file from this
   release.
3. Verify the download with
   `shasum -a 256 -c AeriVoice-v0.1.0-beta.5-arm64.dmg.sha256`.
4. Open the DMG, drag AeriVoice into Applications, and choose **Replace**.
5. Reopen AeriVoice from Applications.

Requires an Apple Silicon Mac running macOS 26 or later, your own transcription
and cleanup provider accounts, and Microphone and Accessibility permissions.

## Validation and distribution

The normal and distribution test suites each passed 248 tests, with three opt-in
live benchmarks skipped. Release static analysis passed. Production insertion
was exercised with synthetic Unicode/newline text in TextEdit, VS Code, and Dia.
This is not complete coverage of every app or a fresh microphone-to-paste test.

The app and DMG are Developer ID signed and notarized by Apple. A checksum and
symbol archive accompany the download. See the repository's beta.5 readiness
record for the detailed validation scope and remaining manual checks.
