# AeriVoice v0.1.0-beta.7 — More cleanup models and native settings

- **More OpenRouter cleanup models:** start with recommended presets, then browse and search compatible text models or enter a model ID. Model capabilities and reasoning options refresh from OpenRouter and are cached for offline use.
- **Native macOS settings:** a permanent sidebar, compact provider rows with icons, simpler headings, and a cleaner model picker. Dictionary entry is left-aligned with Add on the right.
- **Flexible onboarding:** connect one transcription provider and one cleanup provider. OpenRouter is optional; direct Cerebras is supported as a standard option, while Groq remains experimental.
- **Polished by default:** applies when no cleanup style is saved, including existing installations. Explicitly saved styles are preserved.
- **Settings fixes:** scrolling content stays below the toolbar title. Closing Settings dismisses open sheets and cancels credential verification, preventing late responses from saving a dismissed replacement.

OpenRouter is still used for cleanup only, not transcription.

## Updating

Quit AeriVoice, download the DMG and checksum, and verify:

```sh
shasum -a 256 -c AeriVoice-v0.1.0-beta.7-arm64.dmg.sha256
```

Open the DMG, replace AeriVoice in Applications, and reopen it. Existing keys and saved settings are retained. Requires Apple Silicon and macOS 26+.
