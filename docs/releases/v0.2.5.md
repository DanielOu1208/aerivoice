# AeriVoice 0.2.5 — Chosen microphones and pasting into Mail

AeriVoice 0.2.5 fixes dictation failing at once on a microphone chosen in Settings, pastes into a new Mail message instead of copying, and says so when cleanup failed.

### What's fixed

- **A chosen microphone starts:** if the microphone picked under **Settings → Dictation → Microphone** had a different sample rate or channel count from the Mac's default devices, as a USB wireless receiver can, every dictation ended at once with an error. AeriVoice now opens the microphone in its own format.
- **Fallback to the default microphone:** if a chosen microphone is connected but still cannot be started, the dictation runs on the system default instead and the notch shows "Using the default microphone". See [Microphone](../MICROPHONE.md).
- **Paste into a new Mail message:** dictating into Mail's compose body copied the text instead of pasting it. It now pastes.
- **Cleanup failures stay visible:** when cleanup fails and the raw transcript is pasted, the notch shows "Cleanup failed—used raw text" for two seconds. Before, the check mark replaced it almost immediately.
- **Clipboard restored sooner in an empty Notes or Messages field:** a paste into an empty field is now verified, so your clipboard comes back once the text has landed instead of after the fallback delay.

### Install or upgrade

Requires **Apple Silicon and macOS 26 or newer**. Use **Settings → General → Check for Updates**, or download the DMG below, open it, and drag AeriVoice into Applications. Existing settings and Keychain credentials are retained.

The DMG is Developer ID signed, notarized by Apple, and stapled. A SHA-256 checksum and debugging symbols are attached.
