# AeriVoice v0.1.0-beta.6 — Quicker dictation and clipboard restoration

- **Earlier startup:** Soniox connects sooner, and AeriVoice prepares its audio engine at launch without recording.
- **Faster Meta audio delivery:** catch-up continues through the final queued audio fragments.
- **Restore your clipboard:** enabled by default after a verified paste. If verification is unavailable, dictation stays copied. The green check marks Paste dispatch, not confirmed delivery.
- **Optional diagnostics:** off by default, with expired history now removed on startup even when logging is disabled.

## Slightly lower latency

Measured waiting time before recording and after stopping, **excluding talking time**:

| Provider | Before → After | Reduction |
| --- | ---: | ---: |
| Meta | 809 → 688 ms | **121 ms (~15%)** |
| Soniox | 708 → 668 ms | **40 ms (~6%)** |

Medians of two runs per version using the same 3.5-second clip, Cerebras Qwen 3.8 cleanup, and sound cues on. Microphone input and paste were simulated. These are preliminary results; network and cleanup variation affect the difference.

## Updating

Quit AeriVoice, download the DMG and checksum, and verify:

```sh
shasum -a 256 -c AeriVoice-v0.1.0-beta.6-arm64.dmg.sha256
```

Open the DMG, replace AeriVoice in Applications, and reopen it. Uses existing keys and settings; macOS may request permissions. Requires Apple Silicon and macOS 26+.
