# beta.5 release verification

Release: `v0.1.0-beta.5`, marketing version `0.1.0`, build `2026090605`.
The release focuses on safer shared paste, the restored completion check mark,
Cerebras connection warming, timing diagnostics, and benchmark tooling.

The signed app was built from `cddf86f6a2c2cf63ec7478a65e337f33fefe78b8`.
The release preparation changes only documentation; app and project sources are
unchanged from that tested commit. The release tag identifies the final source
and documentation commit.

## Completed automated and artifact checks

- Normal full suite: 248 passed; three opt-in live benchmarks skipped.
- Distribution full suite from a fresh local clone: 248 passed; three opt-in
  live benchmarks skipped.
- Distribution Release static analysis and signed archive passed.
- Developer ID signature, hardened runtime, build number, and arm64 architecture
  verified. The preliminary mounted DMG app matched the archive byte-for-byte.
- Apple accepted app notarization submission
  `b9ac7c54-cf26-4d4f-a092-b5c260cb6ccd` and DMG submission
  `b16ce704-c468-4be3-8af9-d5609c1d8239`. Both tickets were stapled and validated;
  app execution and DMG distribution assessments passed Gatekeeper.
- Final artifacts are under `dist/v0.1.0-beta.5/` and include the DMG, SHA-256
  checksum, and dSYM archive. The earlier `preparation-` candidate is superseded.
- Full Git-history and local-file secret audit passed during preparation;
  release documentation received a separate secret scan and review.
- Existing actor-isolation warning in AppDelegate's wake callback predates this
  release. The usual AppIntents metadata warning remains.

## Runtime and performance evidence

- Production insertion was exercised in TextEdit, VS Code, and Dia using
  synthetic Unicode/newline content. See `../TEXT-INSERTION.md` for exact limits.
- Controlled warming comparison: ten samples per condition, all 20 pipelines
  and correctness checks passed. Median cleanup fell from 301.4 to 217.5 ms;
  median end-of-audio to cleaned text fell from 474.5 to 400.1 ms. These are
  small-sample measurements, not a guaranteed user-visible speedup.
- Six Chinese cleanup requests preserved language/script and technical terms;
  filler removal remained incomplete. See `../benchmarks/`.

## Manual validation not completed for this release

A fresh-user quarantined install/onboarding, beta.4 credential/settings upgrade,
actual microphone-to-provider-to-paste flow, default cleanup, launch at login,
and 96/48 kHz audio-route transitions were not repeated for this artifact.
Cancellation is covered by automated tests. The available native UI tool could
not access AeriVoice during the release smoke, so it provided no new runtime
acceptance evidence.

VS Code provides an Electron insertion check; Discord specifically and Ghostty
live delivery remain unverified. The release notes do not claim full terminal
or app coverage, guaranteed paste consumption, or prompt-free upgrades.

Publishing was explicitly authorized after candidate preparation. Remote CI,
release download checksums, and final tag/asset identity are verified during
publication; they are separate from the local tests recorded above.
