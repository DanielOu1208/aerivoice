# AeriVoice 0.2.2 — Paste and update fixes

AeriVoice 0.2.2 fixes pasting into deeply nested web apps, restores your clipboard after pasting into terminals, and stops update checks from freezing the app.

### What's fixed

- **Pasting into web apps like Claude.ai:** before pasting, AeriVoice checks every container around the text field to make sure it isn't a password field. That check gave up after 32 levels, and some web apps nest their text box deeper (Claude.ai in a Chromium-based browser sits 33 levels down), so the result was copied instead of pasted. The limit is now 128 levels, and every level is still checked.
- **Clipboard restore in terminals:** when an app redraws its screen instead of showing the exact pasted text (for example Claude Code in Ghostty), AeriVoice couldn't confirm the paste and never restored your previous clipboard. It now restores it after the fallback delay set in **Settings → General → Clipboard**. If the field didn't change at all, the dictation stays copied so you can paste it manually.
- **Check for Updates no longer freezes AeriVoice:** while the "You're up to date" message was open, dictation stopped responding, and quitting could hang. Update messages now open without blocking the rest of the app.
- **Crash with performance logging on:** AeriVoice could crash after five idle minutes when performance logging was enabled.

### Install or upgrade

Requires **Apple Silicon and macOS 26 or newer**. Use **Settings → General → Check for Updates**, or download the DMG below, open it, and drag AeriVoice into Applications. Existing settings and Keychain credentials are retained.

The DMG is Developer ID signed, notarized by Apple, and stapled. A SHA-256 checksum and debugging symbols are attached.
